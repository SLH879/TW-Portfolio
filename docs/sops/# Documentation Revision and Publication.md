# Documentation Revision and Publication Workflow
| **Document ID:** SOP-docreview-001 | **Version:** 1.0 | **Last Updated:** August 2026 | **Owner:** | **System:** Company | **Status:** Published |


## Purpose
This document instructs how technical writers should approach the documentation lifecycle, beginning with revision to publication.

## Tools Used
- VS Code as the markdown editor
- Github desktop for reviewing revisions, committing and pushing them online

## Scope

This document will cover:
- Creating a Jira ticket
- Defining the audience, objectives, scope, and acceptance criteria
- Reviewing the document for gaps and discrepancies
- Revising the markdown file on VS Code or a similar editor
- Previewing headings, tables, callouts, and links
- Applying own QA checklist
- Reviewing the file changes in Github desktop
- Committing and pushing the revision
- Verify the published document
