# Documentation QA Checklist

## Content

- [ ] Audience and purpose are defined.
- [ ] Prerequisites are available to the user.
- [ ] Instructions follow a logical sequence.
- [ ] Expected results are documented.
- [ ] Troubleshooting covers likely failures.
- [ ] Technical claims were checked against authoritative sources.

## Editorial

- [ ] Spelling and grammar were reviewed.
- [ ] Terminology is consistent.
- [ ] Headings follow the style guide.
- [ ] Tables and lists render correctly.
- [ ] Links work.

## Document control

- [ ] Document ID is correct.
- [ ] Version matches the revision history.
- [ ] Last-updated date is current.
- [ ] Status and document owner are accurate.

## XML

- [ ] XML is well formed.
- [ ] Opening and closing tags match.
- [ ] The document validates against the applicable DTD or schema.
- [ ] Element nesting follows the content model.
