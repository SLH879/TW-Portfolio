# Documentation Style Guide

## Voice

- Use active voice.
- Address the user in second and third person - either directly as “you" or "employee".
- Begin procedural steps with an imperative verb.
- Use one primary action per numbered step.

## Headings

- Use sentence-style capitalization.
- Do not number headings in short knowledge-base articles.
- Maintain sequential Markdown heading levels.

## Interface elements

- Use bold text for buttons, menus, and fields.
- Match interface labels exactly.
- Use code formatting for commands, filenames, and keyboard input.

## Notes and warnings

- Use a note for supplementary information.
- Use a caution when an action may cause data loss or equipment damage.
- Use a warning only when personal injury or serious harm is possible.
