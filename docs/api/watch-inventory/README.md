# Watch Inventory API

## Overview

A self-directed API documentation project for managing and tracking a personal watch collection. This includes watch identification, ownership status, and buy/sell history.

The project uses watch collection records to explore REST API concepts, OpenAPI specifications, JSON data structures, and documentation.

## Project Scope

The initial version documents retrieval of an individual watch by its unique identifier.

Additional operations for inventory management, transactions, and service records are planned.
